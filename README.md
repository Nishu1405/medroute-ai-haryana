# 🚑 MedRoute AI Haryana

**MedRoute AI Haryana** is an AI-powered, voice-first emergency triage engine that maps Haryana's 5-tier government hospital network (from Tier-1 Apex Institutions like PGIMS Rohtak down to Tier-5 PHCs/CHCs).

---

## 🌟 Key Features

* **Voice-Activated Triage:** Speaks and listens to citizen emergency complaints using the Web Speech API.
* **5-Tier Hospital Mapping:** Dynamically redirects patients based on symptom severity to appropriate centers (PHC, CHC, District Hospital, Medical College, Apex Referral).
* **Instant Priority Passes:** Generates downloadable emergency priority passes with auto-rendered QR codes using `jsPDF` and `QRCode.js`.
* **Ayushman Bharat / Family ID (PPP) Integration:** Enables instant scheme verification for cashless treatment.
* **Real-time Bed & SOS Tracking:** Facilitates direct emergency dispatch routing.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Voice Engine:** Web Speech API
* **PDF & QR Generation:** jsPDF, QRCode.js
